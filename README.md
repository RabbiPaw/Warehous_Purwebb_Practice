## Описание проекта

Система управления складом — это REST API для ведения учета товаров, управления складскими операциями и разграничения доступа пользователей.

### Функциональные возможности

- **Аутентификация и авторизация** — регистрация, вход, JWT-токены, разграничение доступа по ролям
- **Управление пользователями** — создание, редактирование, назначение ролей, активация/деактивация (только администратор)
- **Управление товарами** — CRUD операции, активация/деактивация (администратор, бухгалтер)
- **Управление поставщиками** — CRUD операции, активация/деактивация (администратор, бухгалтер)
- **Управление единицами измерения** — CRUD операции, активация/деактивация (администратор)
- **Товародвижение** — приход (бухгалтер), расход (кладовщик), брак (администратор), корректировка (администратор/бухгалтер)
- **Управление складом** — настройка вместимости, отслеживание занятости, история изменений
- **Курсорная пагинация** — для истории перемещений
- **Soft Delete** — данные не удаляются, только деактивируются
- **Документация API** — Swagger/OpenAPI

### Роли и права доступа

| Роль | Права |
|-|-|--|-------|
| **Администратор** | Полный доступ: управление пользователями, товарами, поставщиками, единицами измерения, складом, всеми типами перемещений |
| **Бухгалтер** | Управление товарами, поставщиками, просмотр единиц измерения, создание прихода и корректировки |
| **Кладовщик** | Создание расхода, просмотр товаров, поставщиков, складов |
| **Неизвестно** | Роль по умолчанию для новых пользователей (без прав) |
